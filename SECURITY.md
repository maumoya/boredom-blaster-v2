# Security policy

## Reporting a vulnerability

If you find a problem, for example a way to forge high scores or to break the scores Worker,
report it privately through GitHub's
[private vulnerability reporting](https://github.com/maumoya/boredom-blaster-v2/security/advisories/new).
You will get an answer within 7 days.

## Supported versions

Only the latest version on `main` (the live game) is supported.
