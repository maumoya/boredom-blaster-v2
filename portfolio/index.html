Engineering

How it's built

Written from scratch in plain JavaScript and the HTML canvas, with no game engine or framework. Static hosting for the game, plus one tiny serverless function for the shared scores.

⚿

A score table that refuses fakes

Every run gets a signed ticket from the server (HMAC with the server's own clock). A score is only accepted with a valid, unused ticket, and only if its waves, play time and points fit the real time that passed. Hand-made or replayed requests are refused. Practice runs never post.

◉

Privacy first

No accounts, no cookies, no IDs. The only stats are anonymous counts of finished runs (wave, length, phone or desktop). Only three initials are ever kept with a score.

A run, end to end

  1. Start: the game asks the Worker for a ticket.
  2. Play: everything runs in the browser at 60 fps.
  3. Game over: initials, score and ticket go to the Worker.
  4. Check: signature, age, one-time use, rate limit and plausibility.
  5. Store: the top 10 is kept in Cloudflare KV.
✓

Tested and shipped safely

338 automated tests cover game rules, upgrades, input, the score server and its anti-cheat checks. Each change is tested locally before it goes live, and the page always loads the newest version.
