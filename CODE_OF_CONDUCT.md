# Code of conduct

Everyone taking part in this project (issues, pull requests, discussions) is expected to:

- Be respectful and assume good intent.
- Keep feedback about the work, never about the person.
- Not harass, insult or demean anyone, in public or private.
- Not post anyone's private information.

Report unacceptable behavior privately to the maintainer through a
[private advisory](https://github.com/maumoya/boredom-blaster-v2/security/advisories/new) or a direct GitHub message to @maumoya.
The maintainer may edit or remove comments, close issues and block accounts that break these rules.
