# Roadmap

What the project intends to do next, and what it will not do. Plans can change; issues hold the details.

## Next

- Keep every CodeQL and Scorecard finding fixed or dismissed with a written reason.
- Fix the known limitation in [docs/SECURITY_CASE.md](docs/SECURITY_CASE.md) (constant-time key check on `/stats`).
- New gameplay ideas are proposed and tracked as GitHub issues before any work starts.

## Not planned

- Accounts, logins, cookies or tracking. Scores stay anonymous (three initials).
- A game engine or build step. The game stays plain JavaScript that runs as-is.
